📱 1. Getting Started & System Overview

What is QuizBattle?

QuizBattle is a real-time quiz competition platform designed for college IT clubs. It supports:

  • Two competing clubs: STACK_PUSH and IT_INNOVATORS
  • 100 questions across 5 difficulty rounds
  • Real-time scoring with server-side validation
  • Live leaderboard visible to all participants
  • Projector display for audience viewing

System Requirements

📌 Device Requirements:
  • Modern web browser (Chrome, Firefox, Safari, Edge)
  • Internet connection (WiFi recommended)
  • Desktop, tablet, or smartphone compatible
  • Screen resolution: 1024×768 or higher recommended

Accessing QuizBattle

1

Open Web Browser

Use any modern web browser (Chrome, Firefox, Safari, or Edge)

2

Navigate to Platform

Enter the event's QuizBattle URL provided by the organizer

3

Choose Your Role

You'll see three options: Join Quiz, Admin Dashboard, or Display Screen

👥 2. For Quiz Participants

Registration Steps

1

Click "JOIN QUIZ"

From the home page, select the "Join Quiz" option

2

Select Your Club

Choose between:

🔵 STACK_PUSH - Club for backend & systems programming

🟢 IT_INNOVATORS - Club for innovation & emerging tech

3

Enter Your Name

Type your full name in the text field (e.g., "John Doe")

4

Click "REGISTER"

Submit your registration. You'll be assigned a unique session ID.

During the Quiz

✨ Quiz Page Layout:
  • Left side: Question text and 4 answer options
  • Right side: Your current score and live leaderboard
  • Top: Connection status indicator
  • Bottom: Submit button

Answering Questions

1

Wait for "LIVE" Status

The question page will show "LIVE" when admin has started a question

2

Read the Question

Carefully read the question text displayed in large font

3

Select Your Answer

Click one of the four answer buttons: A, B, C, or D

4

Click "SUBMIT"

Click the "SUBMIT ANSWER" button to lock in your response

5

Wait for Reveal

After all answers are submitted, the correct answer will be revealed

⚠️ Important Notes:
  • You can only submit ONE answer per question
  • Once submitted, you cannot change your answer
  • Submit as quickly as possible - faster correct answers earn bonus points
  • Stay connected - if you disconnect, you may miss questions

Understanding Your Score

📊 How Scoring Works:

Correct Answer: You earn the full points for that question

Speed Bonus: Faster correct answers may earn bonus points

Wrong Answer: 0 points awarded

Questions vary by round: Earlier rounds = 1 point, Later rounds = 2-3 points

📈 Live Leaderboard:
  • Your personal score appears on the right side
  • Club leaderboard shows both STACK_PUSH and IT_INNOVATORS scores
  • Updates after each submission
  • Leading club is indicated with a crown emoji 👑

Connection Status

Status Meaning Action Required
🟢 ONLINE Connected to quiz server None - you're ready to answer
🔴 OFFLINE Disconnected from server Refresh page or check WiFi connection
🟡 WAITING No active question Wait for admin to start next question

Metric What It Shows
Status Current quiz state (WAITING, LIVE, LOCKED, REVEALED, FINISHED)
Round Current round number (1-5)
Question Current question number (1-100)
Registered Total number of participants
STACK_PUSH / IT_INNOVATORS Number of participants per club

Running a Question (Step-by-Step)

1

Select a Question

Use the question navigator grid at bottom-left. Click a question number or use Round filters to find your question.

2

Preview Question

Below the grid, you'll see the selected question text and points value

3

Click "START QUESTION"

This broadcasts the question to all participants and changes status to "LIVE"

4

Wait for Participants

Participants have 30-60 seconds to read and answer (depends on question difficulty)

5

Click "LOCK ANSWERS"

This closes answer submission and prevents new submissions

6

Click "REVEAL ANSWER"

Shows the correct answer on all screens. Scores are calculated automatically.

7

Click "NEXT QUESTION"

Advances to the next question. Status returns to "WAITING"

Control Buttons Reference

Button Function When to Use
START QUESTION Begins question timer, shows to all participants When you want to activate the current question
LOCK ANSWERS Stops accepting new answers After time's up, before revealing answer
REVEAL ANSWER Shows correct answer, calculates scores After lockdown, to show solution
NEXT QUESTION Advances to next question After revealing answer, to continue
RESET CURRENT Restarts the current question If question was started by mistake
RESET QUIZ Clears all progress, starts over For retrying the entire event
END QUIZ Finalizes results, stops all activity At the end of the competition

Selection: Click any question to select it

Scroll: Grid is scrollable if too many questions shown

Preview: Selected question appears below with text and points

🔧 6. Troubleshooting & FAQ

Common Participant Issues

❓ "I can't see the question"

Solutions:
  • Refresh your browser: Ctrl + R
  • Check internet connection
  • Wait for admin to click "START QUESTION"
  • Try opening in a different browser

❓ "My answer didn't submit"

Solutions:
  • Check your internet connection
  • Verify you selected an answer (one button should be highlighted)
  • Click "SUBMIT" button again
  • If submit button is disabled, answer submission may be closed
  • Refresh page and try again

❓ "Connection shows OFFLINE"

Solutions:
  • Check WiFi/internet connection
  • Move closer to WiFi router if signal is weak
  • Try connecting to different WiFi network
  • Restart your device
  • Clear browser cache: Ctrl + Shift + Delete

❓ "My score doesn't match what I think"

Explanation:
  • Score is calculated server-side (cannot be altered locally)
  • Correct answers: full points + possible speed bonus
  • Wrong answers: 0 points
  • Different rounds have different point values
  • Check leaderboard to see final scores after each question

Common Admin Issues

❓ "Admin login says 'Invalid password'"

Solutions:
  • Verify you're using correct password (case-sensitive)
  • Clear browser cookies and try again
  • Try incognito/private browsing mode
  • Contact event organizer to confirm password

❓ "Questions aren't loading in navigator"

Solutions:
  • Refresh the admin page
  • Check internet connection
  • Wait a moment for questions to load (large data set)
  • Try different browser
  • Contact system administrator

❓ "Leaderboard isn't updating"

Solutions:
  • Scores update after participants submit answers
  • Wait for participants to finish answering current question
  • Refresh admin page to manually sync
  • Check if participants are actually submitting answers

❓ "Display screen is frozen/not updating"

Solutions:
  • Refresh display page: Ctrl + R
  • Check internet connection to display device
  • Close other browser tabs using bandwidth
  • Restart the device
  • Verify admin is clicking buttons (admin controls display)

Frequently Asked Questions

❓ How many participants can join?

The system supports any number of participants. For best performance, 100+ participants should be tested for your specific setup.

❓ Can I pause the quiz?

Yes - by clicking "LOCK ANSWERS" without clicking "REVEAL ANSWER", participants can't answer but quiz isn't progressing.

❓ What happens if I accidentally skip a question?

Click "RESET CURRENT QUESTION" to go back to the current question, or use the question navigator to select any question.

❓ Can participants see other participants' answers?

No - each participant only sees their own score. They can see club scores on the leaderboard.

❓ What if a participant disconnects mid-question?

They can reconnect anytime. If question was already answered by them, they'll receive the score. If not answered, they can't re-answer that question.

❓ How are ties broken?

If clubs have equal scores, they're co-champions. Speed of correct answers can be used as tiebreaker if needed.

❓ Can I change a participant's score?

No - all scoring is automated and server-side. Scores cannot be manually adjusted.

❓ Is the quiz data saved after it ends?

Yes - all submissions, scores, and responses are saved in the database for future review.
